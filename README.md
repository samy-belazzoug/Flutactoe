# Flutactoe

*My very first complete CLI app*

## Description

This project is a very simple implementation of the famous tic tac toe game made with Flutter.

## Features 

This project, because it's made with flutter, have a GUI with : 
- Text that tells you who have to play
- Grid representing the game where you have to interact to place a cross/round.
- Reset button so you can play another game.
- It also have a CLI version of the game which you can try by doing ```dart run .\lib\game.dart``` in flutactoe\ folder.

## Technologies

The technologies used for this project are Dart and flutter, the reasons are simple : 

### Wanted to start mobile programming

It's been a very long time since I wanted to do mobile programming and I didn't knew which Framework use.
So the fact that Flutter has a native support for mobile programming was a big plus.

### Cross platform simplicity

I think it's the main power of Flutter. You don't need to write any CmakeLists or config file to make your app run on any platform.
Your code automatically adapts to all the different platforms, which I find very impressive and pretty practical.

### JIT

The Just-In-Time compilation is a game changer in terms of front-end development for me who was used to C++ and Qt6.
Now, I don't need to completely stop the program, rebuild it then recompile it then waiting for it to execute to see my update, I just have to click one key and the program refresh super quickly.
